<!--Personal Portfolio Website-->

A responsive personal portfolio built with **HTML5** and **CSS3**.  
This project showcases my skills, projects, and contact information in a clean, modern design.

<!--Features-->

- **Semantic HTML5 structure**: Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Responsive design**: Works across mobile, tablet, and desktop using CSS Grid, Flexbox, and media queries.
- **Google Fonts**: Montserrat for headings and Open Sans for body text.
- **Font Awesome icons**: Used for skills and social media links.
- **Interactive hover effects**: Buttons, cards, and icons respond to user interaction.
- **Sections included**:
  - Hero (intro with photo and CTA)
  - About Me
  - Skills (HTML5, CSS3, Flexbox, Grid, Git, GitHub, VS Code, Chrome DevTools)
  - Projects (placeholder projects with descriptions)
  - Contact (form + social media links)
  - Footer (copyright + social icons)

<!--Technologies Used-->

- **HTML5**  
- **CSS3**  
- **Flexbox & Grid** for layout  
- **Font Awesome** for icons  
- **Google Fonts** (Montserrat + Open Sans)
